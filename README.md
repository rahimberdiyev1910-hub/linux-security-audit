# Linux Security & Network Audit Tool

Kali Linux va boshqa Debian asosidagi tizimlarda bazaviy tarmoq holati, ochiq portlar hamda tizim xavfsizligini tezkor tekshirish uchun mo'ljallangan Bash skript.

## Imkoniyatlari
- Tarmoq interfeyslari: Faol tarmoq kartalari va IP manzillarni aniqlash.
- Ochiq portlar auditi: Tizimda tinglayotgan (listening) TCP/UDP portlarni tekshirish.
- Xavfsizlik loglari: Ruxsatsiz kirish urinishlarini kuzatish.

## Ishga tushirish
    git clone [https://github.com/rahimberdiyev1910-hub/linux-security-audit.git](https://github.com/rahimberdiyev1910-hub/linux-security-audit.git)
    cd linux-security-audit
    chmod +x audit.sh
    ./audit.sh
